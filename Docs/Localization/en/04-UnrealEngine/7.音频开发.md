## Understanding Audio

### What is Audio?

As we all know, sound is produced by vibrations, like this:

![How Does Sound Travel From One Medium To Another?](../../../04-UnrealEngine/Resources/OIP-C.jpeg)

> Image source: [How Does Sound Travel From One Medium To Another? (scienceabc.com)](https://www.scienceabc.com/pure-sciences/movement-of-sound-waves-through-different-media.html)

Here are two excellent videos explaining the nature of sound:

- [What is Sound-The Dr. Binocs Show](https://www.bilibili.com/video/BV16C4y187Xy)
- [What is Sound-BranchEducation](https://www.bilibili.com/video/BV1pR4y1L7WD)

We usually regard sound as a continuous waveform, like this:

![image-20240204102619133](../../../04-UnrealEngine/Resources/image-20240204102619133.png)

The storage precision of computers is limited (there are infinitely many decimals between 0 and 1). If we want to store sound data in a computer, we will face precision processing issues in two dimensions:

- Time
- Amplitude

This requires the use of [Pulse Code Modulation (PCM)](https://baike.baidu.com/item/脉冲编码调制/5143788?fromModule=lemma_inlink) to convert the **Continuous Signal** of sound into a **Discrete Signal**.

First, we process the precision division in the time dimension through **Sampling**:

![image-20240204103616957](../../../04-UnrealEngine/Resources/image-20240204103616957.png)

The sampling precision parameter in the time dimension is the **Sample Rate**, which represents the number of times the sound signal is sampled per unit time (1 second). Common sample rates include `44100 Hz`, `48000 Hz`, etc.

After obtaining the sampled data, we further process the precision division in the amplitude dimension through **Quantization**:

![image-20240204104205505](../../../04-UnrealEngine/Resources/image-20240204104205505.png)

The sampling precision in the amplitude dimension is **Bits Per Sample**, which represents the bit storage precision of an audio sample. Common bit depths include `8 bit`, `16 bit`, `24 bit`, and `32 bit`. Taking `8 bit` as an example, it is equivalent to `1 byte` and can represent `256 (2^8)` numbers. Including the sign bit, its value range is `[-128, 127]`, which can be regarded as having 128 amplitude gradients.

Regarding sampling and quantization, here is an excellent article:

- [Introduction to Audio-Video Development Basics | Sound Capture and Quantization, Audio Digital Signal Quality, Audio Bit Rate - Zhihu (zhihu.com)](https://zhuanlan.zhihu.com/p/577850804)

The final data we obtain is generally called a **Wave Table**. If we ignore the storage precision of the bit depth and use floating points to represent the amplitude, in C++, we can express it as the following storage structure:

```c++
std::vector<float> WaveTable = {
    sample0,sample1,sample2,sample3,sample4...
};
```

Opening the computer's sound settings, we can find that each audio device (input or output) has relevant configurations:

![image-20240204105850144](../../../04-UnrealEngine/Resources/image-20240204105850144.png)

In the real world, a **Sound Source** emits a large number of moving particles in all directions. Some particles directly enter the human ear, while others collide with surrounding objects one or more times before entering the human ear. In such a complex surrounding environment, it usually causes the two ears to receive different audio data, which also creates the so-called **Spatial Sense** for audio.

Therefore, to retain this spatial sense when storing audio in a computer, we store multiple copies of audio data. The number of copies is usually called the **Number Of Channels**. Audio with only one channel is called **Mono**, and audio with `2 channels` is called **Stereo**.

Audio samples from multiple channels are interleaved together, and each combination is called an **Audio Block**.

For stereo, its storage structure is as follows:

```c++
std::vector<float> WaveTable = {
    channel0_sample0, channel1_sample0,    	// Block 0
    channel0_sample1, channel1_sample1,		// Block 1
    channel0_sample2, channel1_sample2,		// Block 2
    channel0_sample3, channel1_sample3,		// Block 3
    channel0_sample4, channel1_sample4,		// Block 4
    ...
};
```

The same applies to four channels:

```c++
std::vector<float> WaveTable = {
    channel0_sample0, channel1_sample0, channel2_sample0, channel3_sample0,		// Block 0
    channel0_sample1, channel1_sample1, channel2_sample1, channel3_sample1,		// Block 1
    channel0_sample2, channel1_sample2, channel2_sample2, channel3_sample2,		// Block 2
    channel0_sample3, channel1_sample3, channel2_sample3, channel3_sample3,		// Block 3
    channel0_sample4, channel1_sample4, channel2_sample4, channel3_sample4,		// Block 4
    ...
};
```

Under normal circumstances, a Wave Table cannot be directly played by an audio device because it is a bunch of waveform data without audio format information, such as sample rate, bit depth, number of channels, etc.

To make it playable, we need to further encode it into an audio file.

### WAV

`*.WAV` is one of the most common sound file formats. It is a standard digital audio file developed by Microsoft specifically for Windows. Unlike audio formats such as `*.mp3`, `*.flac`, and `*.aac`, it is an uncompressed audio format that only stores audio format information before the WaveTable data:

![The structure of .wav file format. | Download Scientific Diagram](../../../04-UnrealEngine/Resources/The-structure-of-wav-file-format.png)

Here is a complete document:

- [WAV File Format Analysis and Processing - JianShu (jianshu.com)](https://www.jianshu.com/p/63d7aa88582b)

Please read the above article carefully to understand the meaning of each data in the WAV format.

Afterwards, we can use the following memory alignment in C++ to describe the WAV file header structure:

```c++
struct WavFmtChunk {
    uint8_t chunkID[4] = { 'f','m','t',' ' };
    int32_t chunkSize;
    int16_t audioFormat;
    int16_t numChannels;
    int32_t sampleRate;
    int32_t byteRate;
    int16_t blockAlign;
    int16_t bitsPerSample;
};

struct WavDataChunkHeader {
    uint8_t chunkID[4] = { 'd','a','t','a' };
    int32_t chunkSize;
};

struct WavRiffChunk {
    uint8_t chunkID[4] = { 'R','I','F','F' };
    int32_t chunkSize;
    uint8_t format[4] = { 'W','A','V','E' };
    WavFmtChunk fmtChunk;
    WavDataChunkHeader dataChunkHeader;
};

typedef WavRiffChunk WavHeader;
```

When storing a segment of data in C++, we usually use `std::vector<uint8_t>`. If we want to write a segment of waveform data into a Wav file, we can use the following function:

```c++
void writeWavFile(std::string filePath, int numChannels, int sampleRate, int bitsPerSample, std::vector<uint8_t> waveTable) {
    WavHeader header;
    header.fmtChunk.audioFormat = 0x0001;			// The value corresponding to the PCM format is 0x0001
    header.fmtChunk.chunkSize = 16;					// The audio format of the PCM format occupies 16 bytes. For other formats, it may be >16, which will cause the total file header size to be >44
    header.fmtChunk.numChannels = numChannels;
    header.fmtChunk.bitsPerSample = bitsPerSample;
    header.fmtChunk.sampleRate = sampleRate;
    header.fmtChunk.blockAlign = header.fmtChunk.numChannels * header.fmtChunk.bitsPerSample / 8;
    header.fmtChunk.byteRate = header.fmtChunk.sampleRate * header.fmtChunk.blockAlign;
    header.dataChunkHeader.chunkSize = waveTable.size();
    header.chunkSize = sizeof(header.format) + sizeof(header.fmtChunk) + sizeof(header.dataChunkHeader) + waveTable.size();
    std::ofstream out(filePath, std::ios::out | std::ios::binary);		// Be sure to use std::ios::binary, otherwise the data will be corrupted
    assert(out.is_open() && "Can`t Write File");
    out.write(reinterpret_cast<char*>(&header), sizeof(WavHeader));
    out.write(reinterpret_cast<char*>(waveTable.data()), waveTable.size());
    out.close();
}
```

Reading is also very simple:

```c++
std::vector<uint8_t> readWavFile(std::string filePath) {
    WavHeader header;
    std::ifstream in(filePath, std::ios::in | std::ios::binary);				// Be sure to use std::ios::binary, otherwise the data will be corrupted
    assert(in.is_open() && "Can`t Read File");
    in.read(reinterpret_cast<char*>(&header), sizeof(header));
    int waveTableSize = header.dataChunkHeader.chunkSize;						// Get the size of the waveform data
    std::vector<uint8_t> waveTable(waveTableSize);		
    in.read(reinterpret_cast<char*>(waveTable.data()), waveTableSize);
    return waveTable;
}
```

Next, let's generate an audio waveform. The **Sine Wave** is one of the basic waveforms, and its function is as follows:
$$
y(Time) = Amplitude * sin(2 * PI * Frequency * Time + PhaseOffset) + Bias
$$

According to the function, we can write the following function:

```C++
const double M_PI = 3.1415926535;
std::vector<uint8_t> generateSineWave(int timeLengthSec,	// Duration of the sine wave in seconds
                                            int frequency, 		// Frequency of the sine wave
                                            float amplitude,	// Amplitude of the sine wave
                                            int numChannels, 	// Number of audio channels
                                            int sampleRate, 	// Audio sample rate
                                            int bitsPerSample	// Bit depth of the audio
                                           ) {
    int numBlocks = timeLengthSec * sampleRate;							// Number of audio blocks
    amplitude = std::clamp(amplitude, 0.01f, 1.0f);						// Limit the amplitude, std::clamp requires C++17
    std::vector<uint8_t> waveTable;								
    waveTable.resize(numBlocks * numChannels * bitsPerSample / 8);		// Calculate the memory size required for the audio data
    int step = bitsPerSample / 8;
    for (int i = 0; i < numBlocks; i++) {
        float time = i / (float)numBlocks * timeLengthSec;		// Time point
        float sampleValue = amplitude * std::sin(2 * M_PI * frequency * time);		// Calculate the sample value at the corresponding time point
        // We need to find a way to write sampleValue into waveTable
    }
    return waveTable;
}
```

We face a problem in the above code:

- Through the sine wave function, we get a sample value of type `float`, but the bit depth may be `8 bit`, `16 bit`, `24 bit`, or `32 bit`. How do we convert the float to data of the corresponding bit depth?

A common approach is to use existing data types to assign corresponding data bits, like this:

```c++
const int PCMS16MaxAmplitude = 32767;	 // The value range of 16 bit is [-32768, 32767]. Here we take the minimum absolute value (32767) to avoid overflow

void write16BitSampleValue(uint8_t* dataPtr, float sampleValue) {
    (*reinterpret_cast<int16_t*>(dataPtr)) = sampleValue * PCMS16MaxAmplitude;
}
```

We can also use bitwise operations for filling:

```c++
const int PCMS24MaxAmplitude = 8388607;
void write24BitSampleValue(uint8_t* dataPtr, float sampleValue) {
    int value = sampleValue * PCMS24MaxAmplitude;
    dataPtr[0] = value & 0xFF;
    dataPtr[1] = (value >> 8) & 0xFF;
    dataPtr[2] = (value >> 16) & 0xFF;
}
```

To sum up, we can organize a conversion function table like this:

```c++
const int PCMS8MaxAmplitude = 127;
const int PCMS16MaxAmplitude = 32767;
const int PCMS24MaxAmplitude = 8388607;
const int PCMS32MaxAmplitude = 2147483647;

typedef std::function<void(uint8_t*, float)> SampleValueWriteFunction;
static std::map<uint8_t, SampleValueWriteFunction> SampleValueWriteFunctions = {
    {8,[](uint8_t* dataPtr, float sampleValue) {
         // I don't know why we need to add an offset here for the waveform to be correct =.=
        (*reinterpret_cast<int8_t*>(dataPtr)) = sampleValue * PCMS8MaxAmplitude + PCMS8MaxAmplitude;  
    }},
    {16,[](uint8_t* dataPtr, float sampleValue) {
        (*reinterpret_cast<int16_t*>(dataPtr)) = sampleValue * PCMS16MaxAmplitude;
    }},
    {24,[](uint8_t* dataPtr, float sampleValue) {
        int value = sampleValue * PCMS24MaxAmplitude;
        dataPtr[0] = value & 0xFF;
        dataPtr[1] = (value >> 8) & 0xFF;
        dataPtr[2] = (value >> 16) & 0xFF;
    }},
    {32,[](uint8_t* dataPtr, float sampleValue) {
        (*reinterpret_cast<int32_t*>(dataPtr)) = sampleValue * PCMS32MaxAmplitude;
    }}
};

typedef std::function<float(uint8_t*)> SampleValueReadFunction;
static std::map<uint8_t, SampleValueReadFunction> SampleValueReadFunctions = {
    {8,[](uint8_t* dataPtr) {
        return ((*reinterpret_cast<int8_t*>(dataPtr)) - PCMS8MaxAmplitude) / float(PCMS8MaxAmplitude);
    }},
    {16,[](uint8_t* dataPtr) {
        return (*reinterpret_cast<int16_t*>(dataPtr)) / float(PCMS16MaxAmplitude);
    }},
    {24,[](uint8_t* dataPtr) {
        int value = dataPtr[2];
        value <<= 8;
        value |= dataPtr[1];
        value <<= 8;
        value |= dataPtr[0];
        return value / float(PCMS24MaxAmplitude);
    }},
    {32,[](uint8_t* dataPtr) {
        return (*reinterpret_cast<int32_t*>(dataPtr)) / float(PCMS32MaxAmplitude);
    }}
};
```

```c++
std::vector<uint8_t> generateSineSurroundWave(int timeLengthSec, int frequency, float amplitude, int numChannels, int sampleRate, int bitsPerSample) {
    assert(numChannels == 2);

    int numBlocks = timeLengthSec * sampleRate;							// Number of audio blocks
    amplitude = std::clamp(amplitude, 0.01f, 1.0f);						// Limit the amplitude, std::clamp requires C++17
    std::vector<uint8_t> waveTable;
    waveTable.resize(numBlocks * numChannels * bitsPerSample / 8);
    int step = bitsPerSample / 8;										// Calculate the byte span of each sample
    uint8_t* waveTablePtr = waveTable.data();
    SampleValueWriteFunction writer = SampleValueWriteFunctions.at(bitsPerSample);

    float leftEarPos[2]	 = { -5,0 };									// Position of the left ear (X, Y)
    float rightEarPos[2] = {  5,0 };									// Position of the right ear (X, Y)
    float radiusOfSurround = 10;										// Radius of the surround audio
    float audioAttenuationFactor = 0.7;									// Sound attenuation factor, e.g., 0.7 means the audio attenuates to 0.7 times the original every unit length
    float periodSec = 2;												// Time taken to rotate one circle in seconds, 2 means one circle every two seconds

    for (int i = 0; i < numBlocks; i++) {
        float time = i / (float)numBlocks * timeLengthSec;							// Time corresponding to the current audio block
        float sampleValue = amplitude * std::sin(2 * M_PI * frequency * time);		// Sine value corresponding to the current time

        float angle = 2 * M_PI * time / periodSec;									// Calculate the current rotation angle
        float audioSourcePos[2] = {													// Calculate the current position of the sound source
            radiusOfSurround * std::cos(angle),
            radiusOfSurround * std::sin(angle)
        };

        float leftEarDistance  = sqrt(pow(leftEarPos[0] - audioSourcePos[0], 2) + pow(leftEarPos[1] - audioSourcePos[1], 2));		// Distance from the sound source to the left ear
        float leftSampleValue = sampleValue * pow(audioAttenuationFactor, leftEarDistance);											// Calculate the attenuated audio sample value based on the distance
        writer(waveTablePtr, leftSampleValue);																						// Write to the left channel
        waveTablePtr += step;

        float rightEarDistance = sqrt(pow(rightEarPos[0] - audioSourcePos[0], 2) + pow(rightEarPos[1] - audioSourcePos[1], 2));		// Distance from the sound source to the right ear
        float rightSampleValue = sampleValue * pow(audioAttenuationFactor, rightEarDistance);										// Calculate the attenuated audio sample value based on the distance
        writer(waveTablePtr, rightSampleValue);																						// Write to the right channel
        waveTablePtr += step;
    }
    return waveTable;
}

int main() {
    assert(sizeof(WavHeader) == 44 && "WAV Header Size Error");
    int numChannels = 2;            // Mono
    int sampleRate = 48000;         // Sample rate is 48000 Hz
    int bitsPerSample = 16;         // Each audio sample occupies 16 bits, i.e., 2 bytes
    int auidoLengthSec = 2;         // Generate a 2-second sine wave
    int sineFrequency = 150;        // Frequency of the sine wave
    float sineAmplitude = 0.8f;     // Amplitude of the sine wave
    std::vector<uint8_t> waveTable = generateSineSurroundWave(auidoLengthSec, sineFrequency, sineAmplitude, numChannels, sampleRate, bitsPerSample);
    writeWavFile("./sineWave.wav", numChannels, sampleRate, bitsPerSample, waveTable);
    std::vector<uint8_t> readData = readWavFile("./sineWave.wav");
    assert(readData == waveTable && "Audio Data Error");
    return 0;
}

## Audio Frameworks

### Audio IO Interfaces

With audio, we also need to know how to interact with audio devices. Common audio devices include:

- Input: Microphone
- Output: Speaker, sound system, headphone

These device manufacturers will provide or support relevant audio drivers. Usually, we do not need to directly interact with audio drivers, but use the audio interfaces provided by the operating system to handle audio input and output, such as:

- **Windows:** DirectSound, ASIO, WASAPI
- **Linux:** native ALSA, Jack, OSS
- **Mac OS:** CoreAudio, Jack

For cross-platform audio processing, many frameworks also uniformly encapsulate these interfaces, such as:

- Audio IO module in **Qt Multimedia**: [Audio Overview | Qt Multimedia 6.6.1](https://doc.qt.io/qt-6/audiooverview.html)
- **RtAudio** introduced by **UE**: http://www.music.mcgill.ca/~gary/rtaudio/

### Fourier Transform Libraries

Fourier Transform is an important tool for signal processing.

We know that sound is a continuous signal that changes over time, like this:

Here, the function `UGameplayStatics::PlaySound2D` is used. We can look at its internal implementation:

```c++
void UGameplayStatics::PlaySound2D(const UObject* WorldContextObject, 
                                   USoundBase* Sound, 
                                   float VolumeMultiplier,
                                   float PitchMultiplier, 
                                   float StartTime, 
                                   USoundConcurrency* ConcurrencySettings, 
                                   const AActor* OwningActor,
                                   bool bIsUISound)
{
    if (!Sound || !GEngine || !GEngine->UseSound())
    {
        return;
    }

    UWorld* ThisWorld = GEngine->GetWorldFromContextObject(WorldContextObject, EGetWorldErrorMode::LogAndReturnNull);
    if (!ThisWorld || !ThisWorld->bAllowAudioPlayback || ThisWorld->IsNetMode(NM_DedicatedServer))
    {
        return;
    }

    if (FAudioDeviceHandle AudioDevice = ThisWorld->GetAudioDevice())   // Get the audio output device of the current world
    {
        FActiveSound NewActiveSound;									// Create an active audio
        NewActiveSound.SetSound(Sound);
        NewActiveSound.SetWorld(ThisWorld);

        NewActiveSound.SetPitch(PitchMultiplier);
        NewActiveSound.SetVolume(VolumeMultiplier);

        NewActiveSound.RequestedStartTime = FMath::Max(0.f, StartTime);

        NewActiveSound.bIsUISound = bIsUISound;
        NewActiveSound.bAllowSpatialization = false;

        if (ConcurrencySettings)
        {
            NewActiveSound.ConcurrencySet.Add(ConcurrencySettings);
        }

        NewActiveSound.Priority = Sound->Priority;
        NewActiveSound.SubtitlePriority = Sound->GetSubtitlePriority();

        // If OwningActor isn't supplied to this function, derive an owner from the WorldContextObject
        const AActor* ActiveSoundOwner = OwningActor ? OwningActor : GameplayStatics::GetActorOwnerFromWorldContextObject(WorldContextObject);

        NewActiveSound.SetOwner(ActiveSoundOwner);

        TArray<FAudioParameter> Params;
        UActorSoundParameterInterface::Fill(ActiveSoundOwner, Params);

        AudioDevice->AddNewActiveSound(NewActiveSound, &Params);	// Throw the active audio to the output device for processing
    }
}
```

{
public:

    @param NumSamples		The number of audio samples in the audio buffer

Each node is a functional block that accepts inputs, combines them with the current context of MetaSound execution to populate output data, and the audio generated each frame is stored in the AudioBuffer of MetaSoundSource, waiting for the audio engine to play it.

#### Blueprint Interaction

**MetaSound** is different from Blueprints; it supports relatively limited variables:

![image-20240205152805417](../../../04-UnrealEngine/Resources/image-20240205152805417.png)

You can also extend these variables in C++ by finding appropriate references.

These parameters are not directly exposed to the property editor, so modifying their values is a bit complicated. We can use **UAudioComponent** to simplify this process. It derives from **IAudioParameterControllerInterface**, which provides many convenient interfaces for setting audio parameters:

![image-20240205154502428](../../../04-UnrealEngine/Resources/image-20240205154502428.png)

If you don't want to use **UAudioComponent**, you can refer to the specific implementation of related functions.

It's worth mentioning the `Trigger` in UE's audio system, which is different from the `Delegate` commonly used in C++ code. We can simply treat it as a bool variable, like in this graph:

![image-20240205155420006](../../../04-UnrealEngine/Resources/image-20240205155420006.png)

As we know, each node is executed according to the topological order of dependencies. When the Input executes, it sets the output delegate `When Playing` to true. When `AD Envelope` executes, it reads the node connected to its input delegate `Trigger` (i.e., `When Playing`). If it finds the value is true, it executes the node. After `AD Envelope` finishes executing, it sets the output delegate `When Done` to `true`. At this point, when the `Output` node executes, it detects that the input delegate `When Done` is true and notifies `MetaSoundSource` to stop playing, which happens here:
