# Portal Effect

## Demo

![transfoa12we](../../../../04-UnrealEngine/FX/Resources/transfoa12we.gif)

## Principle

- Create an entry point Blueprint Actor and an exit point Blueprint Actor. The exit point Blueprint contains a `Scene Capture 2D Component` whose perspective parameters are exactly the same as those of the player camera. Synchronize the relative position of the `Scene Capture 2D Component` and the exit point based on the relative position of the player camera and the entry point, as shown below (the red small square corresponds to the Scene Capture Component):

    ![transfoa12w122121e](../../../../04-UnrealEngine/FX/Resources/transfoa12w122121e.gif)

- Display the captured Render Target (RT) on the entry plane using Screen UV.

## Usage

Place `BPA_TransferEntry` and `BPA_TransferExit` in the scene respectively, and specify the corresponding exit Blueprint in the Details panel of `BPA_TransferEntry` to use it normally.

## Notes

- Scene capture has no anti-aliasing.
- Some lighting and shadow functions are based on the player's perspective, so the画面 at the exit may have some abnormalities.
- You need to organize the level streaming logic yourself.
- You need to optimize the lifecycle of perspective synchronization and rendering.
- The player camera component usually has an `Aspect Ratio Constraint` set, which typically follows the project setting `Maintain XFOV`, but the Scene Capture Component internally defaults to `Maintain Aspect Ratio`, which will cause frame desynchronization if inconsistent. This parameter is not exposed by the scene component, so you need to derive and override it yourself for synchronization.
