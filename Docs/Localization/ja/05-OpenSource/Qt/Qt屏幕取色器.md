# Qtスクリーンカラーピッカー

- アドレス：https://github.com/Italink/ColorPicker.git

![img](../../../../05-OpenSource/Qt/Resources/c42c52b30c698cbbd842c6c8f6167e12.gif)

## プログラムの詳細

自動的にルーペの表示位置を調整

自動的にボーダーカラーを切り替え

## 原理

- まず、画面全体を高透明度のボーダーレスウィンドウで覆う（ここでは色を（255, 255, 255）、透明度を1（【0,255】）に設定）
- タイマーまたはスレッドでマウス位置をリアルタイム更新する。マウス移動イベントの使用は避けること。マウス移動でトリガーすると動的な動画の色を取得できないため
- スクリーンショット関数でウィンドウ全体をキャプチャし、マウスを中心とする矩形領域を選択する。ここでは10×7のサイズを選択し、ルーペは100×70なので拡大倍率は10倍となる。この矩形領域の画像をルーペに表示し、マウス位置のピクセルカラーを取得する
- 透明ウィンドウの影響で取得したピクセルカラーに誤差が生じるため、透明度アルゴリズムに基づいて元の色を復元する必要がある
- 透明の原理：Bを透明色、aを透明度、Aを背景色、Cを最終的な表示色とすると、255×C = a×B + (255 - a)×A
- 公式に基づいてAを求めるだけで復元可能
- マウスクリック時に透明ウィンドウを閉じ、カラー信号を送信する

## 使用方法

クラスファイルをインポートし、必要なウィンドウでColorPickerインスタンスを作成するだけ。QWidgetを継承しているため、show関数を呼び出して表示する

信号量 `void QColorPicker::colorSelect(const QColor&)` をconnectすることで、選択した色を取得できる

接続アイコンファイルをインポートすることに注意。そうしないと正確に色を取得できない可能性がある
