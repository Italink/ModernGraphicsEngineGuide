# オーディオビジュアライゼーションアナライザ

- Githubリポジトリ：https://github.com/Italink/SpectrumEngine

ブロガーは最近specinkerのエンジンを静的リンクライブラリにカプセル化しました。もしあなたもプログラミングができ、かつ[スペクトル](https://so.csdn.net/so/search?q=スペクトル&spm=1001.2101.3001.7020)が好きなら、本当にラッキーです。

## 少しの余談

ブロガーは当初、動的リンクライブラリにカプセル化すれば、dllを呼び出せる言語（c/c++、java、python...）で統一的に使用できると思っていました。アイデアは良かったのですが、javaやpythonは言うまでもなく、QtからVSに移植することさえ非常に困難でした。理由はQtのデフォルトコンパイラがMinGWで、生成される静的リンクライブラリファイルが.a形式であることです。一方VSは.aを解析できず、.libライブラリしか解析できないため、MSVCで再コンパイルし、各種システムライブラリをリンクした後、実行はできましたが、呼び出すとエラーが発生します。原因はコード内でスレッドを作成し、Qtの一部機能を使用する際にQApplicationが必要であり、これにはVSでQtの実行環境を構築する必要があるからです。数日間作業を行った結果、カプセル化したライブラリは依然としてQt内でのみ使用可能（VS上でもQt環境を構築する必要がある）で、かつC++からのみ呼び出せることがわかりました。そこで別のルートとして、システムの共有メモリを介してデータを伝送する方法を思いつきました。これによりスペクトルデータをクロス言語で処理できますが、処理が比較的煩雑であり、最近はこの作業を行う時間がありません。もし解決策を知っている場合は、ぜひ教えてください！
