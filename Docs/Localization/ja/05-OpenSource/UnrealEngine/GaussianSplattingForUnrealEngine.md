# Gaussian Splatting For Unreal Engine

- リポジトリアドレス：https://github.com/Italink/GaussianSplattingForUnrealEngine/

**GaussianSplattingForUnrealEngine** は、Unreal Engineのグラフィックスを簡単に高品質な3Dガウス点群に変換できるUnreal Engineプラグインです：

![3dgs](../../../../05-OpenSource/UnrealEngine/Resources/3dgs.gif)

![image-20250118162622141](../../../../05-OpenSource/UnrealEngine/Resources/image-20250118162622141.png)

このプラグインは以下の機能をサポートしています：

- 使いやすいエディタツールを提供し、以下の操作を実行できます：
    - グラフィックスキャプチャ
    - スパース点群再構成
    - ガウストレーニング
- ガウス点群（`*.ply`）のインポートをサポートし、Unreal内で **GPUパーティクル** または **静的メッシュ** をキャリアとしてレンダリングします
- 3Dガウスを工業生産に近づけるため、非常に有用なメカニズムを提供しています：
    - きめ細かい深度トリミング：浮遊ノイズ点を効果的に除去
    - スクリーンサイズに基づくLOD戦略：ガウス点の特徴に基づき、パーティクルの数とメモリを効率的に調整

3Dガウスには以下の長所と短所があります：

- 長所：
    - 【点】に基づく表現は三角形に比べ、パーティクルエフェクトの制作により適しています
    - 画像特徴認識に基づく再構成は、従来のメッシュ簡略化に比べ通常より良い簡略化効果があり、広範囲の領域のビジュアルプロキシ制作に非常に適しています
    - テクスチャデータがなく、特徴に基づく頂点データのみ存在し、微分可能な特性により自由なカッティングと圧縮が可能です
- 短所：
    - 半透明オーバーレイの方式でレンダリングするため、プリミティブの半透明ソートが必要で、且つOverDrawが高いです
    - 物体の視覚的な色表現のみを復元し、物体の実際の物理属性を復元することはできないか非常に難しいため、動的な光影効果を作り出すことができません
