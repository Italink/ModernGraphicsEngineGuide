# ポータル効果

## デモ

![transfoa12we](../../../../04-UnrealEngine/FX/Resources/transfoa12we.gif)

## 原理

- 入口ポイントと出口ポイントのBlueprint Actorを作成し、出口ポイントのBlueprintには`Scene Capture 2Dコンポーネント`を追加します。このコンポーネントの視点パラメータがプレイヤーカメラのパラメータと完全に一致するようにし、プレイヤーカメラと入口ポイントの相対位置に基づいて、`Scene Capture 2Dコンポーネント`と出口ポイントの相対位置を同期させます（赤い小さな四角がScene Captureコンポーネントに対応します）。

    ![transfoa12w122121e](../../../../04-UnrealEngine/FX/Resources/transfoa12w122121e.gif)

- キャプチャしたRTをScreen UVと組み合わせて入口の平面に表示します。

## 使用方法

シーンに`BPA_TransferEntry`と`BPA_TransferExit`をそれぞれ配置し、BPA_TransferEntryの詳細パネルで対応する出口Blueprintを指定すると、正常に使用できます。

## 注意事項

- Scene Captureにはアンチエイリアスがありません。
- 一部の光影機能はプレイヤー視点に基づいているため、出口の画面に異常が発生する可能性があります。
- レベルのストリーミングロジックは自分で組織する必要があります。
- 視点の同期と描画のライフサイクルを最適化する必要があります。
- プレイヤーカメラコンポーネントは通常`アスペクト比制約`が設定されており、プロジェクト設定の`X軸視野を維持`に従うことが多いですが、Scene Captureコンポーネント内部のデフォルト設定は`主軸視野を維持`です。このパラメータが一致しないと画面が同期しなくなります。Scene Captureコンポーネントはこのパラメータを公開していないため、同期するには自分で派生させてオーバーライドする必要があります。
