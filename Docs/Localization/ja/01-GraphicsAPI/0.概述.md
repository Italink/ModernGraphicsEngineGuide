### ラスタライゼーション

グラフィックスとは何でしょうか？

三角形、長方形、矩形、円、コップのような形状...。これらの多くのものを考慮する必要があると、コンピューターは無数の規則を定義することになります。そのため、自然界のすべてのグラフィックスを包含する最小の基礎単位を使用して簡略化する必要があります。コンピューターはこれらの基礎単位の描画だけを処理すれば良く、これらの基礎単位（プリミティブ）は以下の通りです。

- 点（Point）
- 線（Line）
- 三角面（Triangle）

これらは次のようなデータ構造で記述できます。

``` c++
struct Point {
	int x, y;
};

struct Line {
	std::array<Point, 2> points;
};

struct Triangle {
	std::array<Point, 3> vertices;
};
```

点を`FrameBuffer`に描画するのは簡単です。

``` c++
void drawPoint(std::vector<std::vector<char>>& frameBuffer, const Point& point) {
	frameBuffer[point.x][point.y] = '1';
}
```

では、線を`FrameBuffer`に描画するにはどうすれば良いでしょうか？

線は一連の点で構成されますが、線には無数の点が存在するのに対し、`FrameBuffer`上の点は有限であることに注意が必要です。そのため、描画時に一部の精度が失われ、精度に応じて対応する点の座標を計算するだけで良いです。このプロセスが**ラスタライゼーション**（[Rasterisation](https://en.wikipedia.org/wiki/Rasterisation)）です。

線は斜截式y = kx+bで表すことができます。

2点の座標から`k`と`b`の値を求め、精度を1に設定すると、端点間の他の点を容易に計算できます。但し、斜截式はx軸に垂直な直線を表すことができないため、傾きの計算を回避する必要があります。この方法が**DDA**（[Digital differential analyzer](https://en.wikipedia.org/wiki/Digital_differential_analyzer_(graphics_algorithm))）で、簡易的な実装は以下の通りです。

``` c++
void drawLine(std::vector<std::vector<char>>& frameBuffer, Line line) {
	int dx = line.points[1].x - line.points[0].x;
	int dy = line.points[1].y - line.points[0].y;

	if (dx == 0 && dy == 0) {			//端点が重なる場合、直接点を描画	
		drawPoint(frameBuffer, line.points[0]);
	}

	int steps = abs(dx) > abs(dy) ? abs(dx) : abs(dy);

	float xInc = dx / (float)steps;		//xの増分
	float yInc = dy / (float)steps;		//yの増分

	float x = line.points[0].x;			//xの開始値
	float y = line.points[0].y;			//yの開始値

	for (int i = 0; i <= steps; i++) {	//
		drawPoint(frameBuffer, Point(round(x), round(y)));
		x += xInc;
		y += yInc;
	}
}
```

``` c++
void drawTriangle(std::vector<std::vector<char>>& frameBuffer, Triangle triangle) {
	std::sort(triangle.vertices.begin(), triangle.vertices.end(), [](const Point& a, const Point& b) {
		return a.y < b.y;
	});
	if (triangle.vertices[0] == triangle.vertices[1]	//重なる頂点が出現した場合、描画しない
		|| triangle.vertices[1] == triangle.vertices[2]
		|| triangle.vertices[0] == triangle.vertices[2]
		)
		return;

	auto fillBottomFlatTriangle = [&](const Point& v1, const Point& v2, const Point& v3) {
		float invslope1 = (v2.x - v1.x) / (v2.y - v1.y);
		float invslope2 = (v3.x - v1.x) / (v3.y - v1.y);

		float curx1 = v1.x;
		float curx2 = v1.x;

		for (int scanlineY = v1.y; scanlineY <= v2.y; scanlineY++) {
			Line scanLine = {
			 (int)curx1, scanlineY ,
			 (int)curx2, scanlineY 
			};
			drawLine(frameBuffer, scanLine);
			curx1 += invslope1;
			curx2 += invslope2;
		}
	};

	auto fillTopFlatTriangle = [&](const Point& v1, const Point& v2, const Point& v3) {
		float invslope1 = (v3.x - v1.x) / (float)(v3.y - v1.y);
		float invslope2 = (v3.x - v2.x) / (float)(v3.y - v2.y);

		float curx1 = v3.x;
		float curx2 = v3.x;

		for (int scanlineY = v3.y; scanlineY > v1.y; scanlineY--) {
			Line scanLine = {
			 (int)curx1, scanlineY ,
			 (int)curx2, scanlineY
			};
			drawLine(frameBuffer, scanLine);
			curx1 -= invslope1;
			curx2 -= invslope2;
		}
	};
	if (triangle.vertices[1].y == triangle.vertices[2].y) {
		fillBottomFlatTriangle(triangle.vertices[0], triangle.vertices[1], triangle.vertices[2]);
	}
	else if (triangle.vertices[0].y == triangle.vertices[1].y) {
		fillTopFlatTriangle(triangle.vertices[0], triangle.vertices[1], triangle.vertices[2]);
	}
	else {
		Point mid = Point({
			(int)(triangle.vertices[0].x + ((float)(triangle.vertices[1].y - triangle.vertices[0].y) / (float)(triangle.vertices[2].y - triangle.vertices[0].y)) * (triangle.vertices[2].x - triangle.vertices[0].x))
			, triangle.vertices[1].y
		});
		fillBottomFlatTriangle(triangle.vertices[0], triangle.vertices[1], mid);
		fillTopFlatTriangle(triangle.vertices[1], mid, triangle.vertices[2]);
	}
}
```

``` c++
	if (triangle.vertices[1].y == triangle.vertices[2].y) {
		fillBottomFlatTriangle(triangle.vertices[0], triangle.vertices[1], triangle.vertices[2]);
	}
	else if (triangle.vertices[0].y == triangle.vertices[1].y) {
		fillTopFlatTriangle(triangle.vertices[0], triangle.vertices[1], triangle.vertices[2]);
	}
	else {
		Point mid = Point({
			(int)(triangle.vertices[0].x + ((float)(triangle.vertices[1].y - triangle.vertices[0].y) / (float)(triangle.vertices[2].y - triangle.vertices[0].y)) * (triangle.vertices[2].x - triangle.vertices[0].x))
			, triangle.vertices[1].y
		});
		fillBottomFlatTriangle(triangle.vertices[0], triangle.vertices[1], mid);
		fillTopFlatTriangle(triangle.vertices[1], mid, triangle.vertices[2]);
	}
}
```

### 処理パイプライン

コンピューターでは素朴で静的な幾何学的グラフィックスだけでなく、動的で処理されたグラフィックス効果を描画する必要がある場合があります。そのため、以下の機能が必要です。

- 各頂点に対して移動、座標原点に対する回転、スケーリングなどの処理を行える
- FrameBuffer上のピクセルに対して色付け、各種フィルターの追加などの追加加工を行える

前のセクションの`SwapChain`を組み合わせると、次のような小さなプログラムを実装できます。

上図では三角形のサイズを動的にスケーリングし、*のボーダーを追加しています。完整なコードは以下の通りです。

``` c++
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
#include <array>
#include <Windows.h>

double GTime = 0;

struct Point {
	int x, y;
	bool operator == (const Point& other) { return x == other.x && y == other.y; }
};

struct Line {
	std::array<Point, 2> points;
};

struct Triangle {
	std::array<Point, 3> vertices;
};

void drawPoint(std::vector<std::vector<char>>& frameBuffer, const Point& point) {
	frameBuffer[point.x][point.y] = '1';
}

void drawLine(std::vector<std::vector<char>>& frameBuffer, Line line) {
	int dx = line.points[1].x - line.points[0].x;
	int dy = line.points[1].y - line.points[0].y;

	if (dx == 0 && dy == 0) {			//端点が重なる場合、直接点を描画	
		drawPoint(frameBuffer, line.points[0]);
	}

	float steps = abs(dx) > abs(dy) ? abs(dx) : abs(dy);

	float xInc = dx / (float)steps;		//xの増分
	float yInc = dy / (float)steps;		//yの増分

	float x = line.points[0].x;			//xの開始値
	float y = line.points[0].y;			//yの開始値

	for (int i = 0; i <= steps; i++) {
		drawPoint(frameBuffer, Point(round(x), round(y)));
		x += xInc;
		y += yInc;
	}
}

void drawTriangle(std::vector<std::vector<char>>& frameBuffer, Triangle triangle) {
	std::sort(triangle.vertices.begin(), triangle.vertices.end(), [](const Point& a, const Point& b) {
		return a.y < b.y;
	});
	if (triangle.vertices[0] == triangle.vertices[1]	//重なる頂点が出現した場合、描画しない、一時的に共線の場合を無視
		|| triangle.vertices[1] == triangle.vertices[2]
		|| triangle.vertices[0] == triangle.vertices[2]
		)
		return;

	auto fillBottomFlatTriangle = [&](const Point& v1, const Point& v2, const Point& v3) {
		float invslope1 = (v2.x - v1.x) / (v2.y - v1.y);
		float invslope2 = (v3.x - v1.x) / (v3.y - v1.y);

		float curx1 = v1.x;
		float curx2 = v1.x;

		for (int scanlineY = v1.y; scanlineY <= v2.y; scanlineY++) {
			Line scanLine = {
			 (int)curx1, scanlineY ,
			 (int)curx2, scanlineY 
			};
			drawLine(frameBuffer, scanLine);
			curx1 += invslope1;
			curx2 += invslope2;
		}
	};

	auto fillTopFlatTriangle = [&](const Point& v1, const Point& v2, const Point& v3) {
		float invslope1 = (v3.x - v1.x) / (float)(v3.y - v1.y);
		float invslope2 = (v3.x - v2.x) / (float)(v3.y - v2.y);

		float curx1 = v3.x;
		float curx2 = v3.x;

		for (int scanlineY = v3.y; scanlineY > v1.y; scanlineY--) {
			Line scanLine = {
			 (int)curx1, scanlineY ,
			 (int)curx2, scanlineY
			};
			drawLine(frameBuffer, scanLine);
			curx1 -= invslope1;
			curx2 -= invslope2;
		}
	};
	if (triangle.vertices[1].y == triangle.vertices[2].y) {
		fillBottomFlatTriangle(triangle.vertices[0], triangle.vertices[1], triangle.vertices[2]);
	}
	else if (triangle.vertices[0].y == triangle.vertices[1].y) {
		fillTopFlatTriangle(triangle.vertices[0], triangle.vertices[1], triangle.vertices[2]);
	}
	else {
		Point mid = Point({
			(int)(triangle.vertices[0].x + ((float)(triangle.vertices[1].y - triangle.vertices[0].y) / (float)(triangle.vertices[2].y - triangle.vertices[0].y)) * (triangle.vertices[2].x - triangle.vertices[0].x))
			, triangle.vertices[1].y
		});
		fillBottomFlatTriangle(triangle.vertices[0], triangle.vertices[1], mid);
		fillTopFlatTriangle(triangle.vertices[1], mid, triangle.vertices[2]);
	}
}

/*頂点ごとの処理
* 時間に基づいて頂点位置を動的にスケーリング
*/
Point processVertex(const Point& point) {
	Point newPoint = point;
	double scaleFactor = 0.5 + 0.4 * std::sin(GTime);		//スケーリング因子を[0.1,0.9]に保証
	newPoint.x *= scaleFactor;
	newPoint.y *= scaleFactor;
	return newPoint;
}

/*ピクセルごとの処理
* 簡単な縁取り
*/
char processPixel(const std::vector<std::vector<char>>& frameBuffer, int x,int y) {
	static int direction[4][2] = { {0,1},{0,-1},{1,0},{-1,0} };	//四方向
	for (int i = 0; i < 4; i++) {
		int xOff = x + direction[i][0];
		int yOff = y + direction[i][1];
		if (xOff >= 0											//frameの境界内にあるか判断、現在のピクセルが0で、周辺のピクセルに1がある
			&& xOff < frameBuffer.size()
			&& yOff >= 0 
			&& yOff < frameBuffer[0].size()
			&& frameBuffer[x][y]=='0'
			&& frameBuffer[xOff][yOff] == '1') {
			return '*';
		}
	}
	return frameBuffer[x][y];
}

void renderFrame(std::vector<std::vector<char>>& frameBuffer) {
	std::vector<Triangle> triangles = { 
		{0,0,40,0,20,19},
	};

    /*頂点処理*/
	for (auto& triangle : triangles) {
		for (auto& vertex : triangle.vertices) {
			vertex = processVertex(vertex);
		}
	}

	for (const auto& triangle : triangles) {
		drawTriangle(frameBuffer,triangle);
	}

    /*ピクセル処理*/
	std::vector<std::vector<char>> newFrameBuffer(frameBuffer);
	for (int x = 0; x < frameBuffer.size(); x++) {
		for (int y = 0; y < frameBuffer[x].size(); y++) {
			newFrameBuffer[x][y] = processPixel(frameBuffer, x, y);
		}
	}
	frameBuffer = newFrameBuffer;
}

int main() {
	HANDLE frontendBuffer = GetStdHandle(STD_OUTPUT_HANDLE);        //デフォルトのバッファを取得
	HANDLE backendBuffer = CreateConsoleScreenBuffer(               //新しいバッファをバックグラウンドバッファとして作成
		GENERIC_READ | GENERIC_WRITE,
		FILE_SHARE_READ | FILE_SHARE_WRITE,
		NULL,
		CONSOLE_TEXTMODE_BUFFER,
		NULL
	);
	//両方のバッファのカーソルを非表示
	CONSOLE_CURSOR_INFO cci;
	cci.bVisible = 0;
	cci.dwSize = 1;
	SetConsoleCursorInfo(frontendBuffer, &cci);
	SetConsoleCursorInfo(backendBuffer, &cci);

	const int width = 40;
	const int height = 20;
    const char clearCh = '0';
	const int MaxBufferSize = width * height * 10;

	char bufferData[MaxBufferSize];     //キャッシュデータの一時保存領域
	DWORD bufferLength = 0;
	COORD zeroCoord = { 0,0 };
	while (true) {
		GTime += 0.01;
		bufferLength = 0;
		CONSOLE_SCREEN_BUFFER_INFO backendBufferInfo;      
		GetConsoleScreenBufferInfo(backendBuffer, &backendBufferInfo);
		int lineWidth = backendBufferInfo.srWindow.Right - backendBufferInfo.srWindow.Left + 1;

		std::vector<std::vector<char>> frameBuffer(width, std::vector<char>(height, clearCh));
		renderFrame(frameBuffer);

		for (int y = 0; y < height; y++) {
			for (int x = 0; x < width; x++) {
				bufferData[bufferLength++] = frameBuffer[x][y];
			}
			while (bufferLength % lineWidth != 0) {             //改行効果を達成するために文字を埋める
				bufferData[bufferLength++] = ' ';
			}
		}

		WriteConsoleOutputCharacterA(backendBuffer, bufferData, bufferLength, zeroCoord, &bufferLength);
		SetConsoleActiveScreenBuffer(backendBuffer);           
		std::swap(backendBuffer, frontendBuffer);              
	}
	return 0;
}
```

## グラフィックスAPI

> [**グラフィックスAPI**](https://en.wikipedia.org/wiki/List_of_3D_graphics_libraries)はGPUハードウェアへの抽象的なアクセス方法を提供し、コンピューターグラフィックス生成の各段階を簡略化します。これにより、開発者はハードウェアの詳細を深く理解する必要がなく、グラフィックスの構築に集中できます。
>
> それは純粋に[ソフトウェア](https://en.wikipedia.org/wiki/Computer_software)で完成し[CPU](https://en.wikipedia.org/wiki/Central_processing_unit)上で実行できます。これは[組み込みシステム](https://en.wikipedia.org/wiki/Embedded_system)でよく見られます。または[GPU](https://en.wikipedia.org/wiki/Graphics_processing_unit)による[ハードウェアアクセラレーション](https://en.wikipedia.org/wiki/Hardware_acceleration)によって実行できます。これは[PC](https://en.wikipedia.org/wiki/Personal_computer)でよく見られ、主に[ビデオゲーム](https://en.wikipedia.org/wiki/Video_game)と[シミュレーション](https://en.wikipedia.org/wiki/Simulation_video_game)に使用されます。
>

現在主流の3DグラフィックスAPIは以下の通りです。

- DX11、[DX12](https://www.nvidia.com/en-sg/geforce/technologies/dx12/)：[マイクロソフト](https://zh.wikipedia.org/wiki/微軟)社が[Windows](https://zh.wikipedia.org/wiki/Microsoft_Windows)システム上で開発した3Dグラフィックスプログラミングインターフェース
- [OpenGL](https://www.opengl.org/)：OpenGLは言語を超え、プラットフォームを超えるAPIです。その実装はWindows、一部のUNIX、Mac OSに存在し、これらの実装は一般的にグラフィックスカードベンダーによって提供され、そのベンダーが提供するハードウェアに非常に依存します。
- [Vulkan](https://www.vulkan.org/)：次世代のOpenGLです。比較すると、Vulkanはより低レベルに近く、CPUコアを効率的に割り当てて並列タスクを実行できます。
- [Metal](https://developer.apple.com/metal/)：Metal APIはApple社が提供するAPIで、[iOS](https://en.wikipedia.org/wiki/IOS)、[iPadOS](https://en.wikipedia.org/wiki/IPadOS)、[macOS](https://en.wikipedia.org/wiki/MacOS)、[tvOS](https://en.wikipedia.org/wiki/TvOS)上のアプリケーションがGPUハードウェアへの低レベルアクセスを通じて性能を向上させることを目的としています。Vulkan、DX12と同様に低レベルAPIに属します。

多くの人がこれらを見た最初の反応は以下の通りでしょう。

- これらのAPIの中で誰が最強ですか？どれを学べば良いですか？

この問題については、それぞれの見解があります。例えば：

- [知乎：VulkanはOpenGL、DX12、Metal、Mantleと比較してどのような長所と短所がありますか？](https://www.zhihu.com/question/46536915)

過来人として、筆者の見解は以下の通りです。

- どれか一つのAPIを学んだからといって安心できるわけではありません。実際の開発では、少なくとも上記APIの2つ以上に接触することになり、さらに多くの場合、これらのAPIの上位インターフェースで開発することになります。

大多数のゲームエンジンはこれらのグラフィックスAPIを統一的なインターフェースにカプセル化し、異なるプラットフォームで切り替えてより良いグラフィックス性能を追求できます。このインターフェースは一般的に**RHI**（Rendering Hardware Interface）と呼ばれます。

### QRhi

Qt6の主な目標の一つは、Qtが直接OpenGLを使用することから脱却し、適切な抽象化を通じて、より広範なグラフィックスAPI（例えば[Vulkan](https://www.khronos.org/vulkan/)、[Metal](https://developer.apple.com/metal/)、[Direct3D](https://docs.microsoft.com/en-us/windows/win32/direct3d)）で操作できるようにすることです。[OpenGL](https://www.khronos.org/opengl/)（および[OpenGL ES](https://www.khronos.org/opengles/)）。この背後の主な動機は性能を向上させることではなく、OpenGLが利用できないか不要になったプラットフォームとデバイスでも、**Qtがどこにでも存在する**ことを確保し、将来もそうであることを保証することです。同时に、現代的な低レベルの明示的API上で構築することで、性能の向上（例えばAPIオーバーヘッドの削減によるCPU使用率の低下）も実現できます。它は[Qt Quick](https://doc.qt.io/qt-5/qtquick-index.html#)と他のモジュールの背後にあるレンダリングエンジンであり、そのアーキテクチャは以下の通りです。

> 公式の現在の開発者ブランチでは、QRhiはすでにDX12をサポートしており、Qt6.6でリリースされる予定です。

また、Qt6ではOpenGL互換のGLSLシェーダーコードを使用しなくなり、VulkanスタイルのGLSLで記述した後、反射して他のシェーダー言語（HLSL、MSL）に翻訳し、最後にシリアライズ可能なQShaderオブジェクトにパッケージ化してQRhiが使用できるようになります。そのワークフローは以下の通りです。

![着色器调节](../../../01-GraphicsAPI/Resources/shaderconditioning.pngwidth=1280&name=shaderconditioning.png)

以下の位置でそのソースコードを見つけることができます。

![image-20230224200924150](../../../01-GraphicsAPI/Resources/image-20230224200924150.png)

其中、关键ファイルは以下の通りです。

- qrhi_p.h：各種グラフィックスリソースの構造と操作を定義
- qrhi.cpp：QRhiのスケジューリング実装、大量のコメント説明が含まれている
- qrhi_p_p.h：QRhiの完整な構造骨格を定義

他の`qrhi`で始まるファイルは特定のグラフィックスAPIの具体的な実装です。

### 示例

```cmake
cmake_minimum_required(VERSION 3.12)

include(QtSetup)
include(QtCMakeHelpers)
```
