# 오디오 시각화 분석기

- Github 저장소: https://github.com/Italink/SpectrumEngine

블로거는 최근 specinker 엔진을 정적 링크 라이브러리로封装했습니다. 만약 당신도 프로그래밍을 할 수 있고 [스펙트럼](https://so.csdn.net/so/search?q=频谱&spm=1001.2101.3001.7020)을 좋아한다면 정말 운이 좋으신 것입니다.

## 몇 가지 잡담

블로거는 원래 동적 링크 라이브러리로封装하면 dll을 호출할 수 있는 언어(c/c++, java, python...)에서 통일하게 사용할 수 있을 것이라고 생각했습니다. 아이디어는 좋았지만, java나 python은 말할 것도 없고 Qt에서 VS로 이식하는 것조차 매우 어려웠습니다. 그 이유는 Qt의 기본 컴파일러가 MinGW로, 생성된 정적 링크 라이브러리 파일이 .a이기 때문입니다. 반면 vs는 .a를解析할 수 없고 .lib 라이브러리만解析할 수 있으므로, 다시 MSVC로 컴파일하고 각종 시스템 라이브러리를 링크한 후 실행할 수 있었지만 호출하자마자 오류가 발생했습니다. 그 원인은 코드에서 스레드를 생성하고 Qt의 일부 기능을 사용할 때 QApplication이 필요했는데, 이것은 VS에서 Qt의 실행 환경을搭建해야 했기 때문입니다. 며칠 동안 애썼지만封装한 라이브러리는 여전히 Qt에서만 사용할 수 있고(VS에서도 Qt 환경을搭建해야 함),而且 C++를 통해서만 호출할 수 있다는 것을 발견했습니다. 저는 시스템의 공유 메모리를 통해 데이터를 전달하는 다른 경로를 생각했습니다. 이렇게 하면 스펙트럼 데이터를跨语言 처리할 수 있지만 처리 과정이 비교적麻烦하고 최근 시간도 없어서 이 일을 하지 못했습니다. 만약 해결 방법을 알고 있다면 꼭 저에게 알려주세요!
