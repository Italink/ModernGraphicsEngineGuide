# Gaussian Splatting For Unreal Engine

- 저장소 주소: https://github.com/Italink/GaussianSplattingForUnrealEngine/

**GaussianSplattingForUnrealEngine**은 언리얼 엔진 플러그인으로, 언리얼 내 그래픽을 쉽게 고품질 3D 가우시안 포인트 클라우드로 변환할 수 있습니다:

![3dgs](../../../../05-OpenSource/UnrealEngine/Resources/3dgs.gif)

![image-20250118162622141](../../../../05-OpenSource/UnrealEngine/Resources/image-20250118162622141.png)

이 플러그인은 다음 기능을 지원합니다:

- 사용하기 쉬운 편집기 도구를 제공하여 다음 작업을 수행합니다:
    - 그래픽 캡처
    - 희소 포인트 클라우드 재구성
    - 가우시안 학습
- 가우시안 포인트 클라우드(`*.ply`)의 가져오기를 지원하며, 언리얼에서 **GPU 파티클** 또는 **정적 메시**를载体로 렌더링합니다
- 3D 가우시안을 산업 생산에 더 가깝게 만들기 위해 매우 유용한 메커니즘을 제공합니다:
    - 정교한 깊이 트리밍: 부유 노이즈를 효과적으로 제거합니다
    - 화면 크기 기반 LOD 전략: 가우시안 포인트의 특징을 기반으로 파티클 수와 메모리를 효율적으로 조절합니다

3D 가우시안의 장단점은 다음과 같습니다:

- 장점:
    - 【포인트】 기반 표현은 삼각형에 비해 파티클 효과 제작에 더 적합합니다
    - 이미지 특징 인식 기반 재구성은 기존 메시 단순화에 비해 일반적으로 더 좋은 단순화 효과를 가지며, 넓은 영역의 시각적 프록시 제작에 매우 적합합니다
    - 텍스처 데이터가 없고 특징 기반 정점 데이터만 존재하며, 미분 가능한 특성으로 자유로운 자르기와 압축이 가능합니다
- 단점:
    - 반투명 중첩 방식으로 렌더링하므로, 도형에 대한 반투명 정렬이 필요하며 OverDraw가 높습니다
    - 물체의 시각적 색상 표현만还原할 뿐, 물체의 실제 물리 속성을还原하거나很难还原하므로 동적 광원 효과를营造할 수 없습니다
