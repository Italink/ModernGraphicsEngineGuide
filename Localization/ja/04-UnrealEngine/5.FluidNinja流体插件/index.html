    Fluid Ninja¶

    Fluid Ninja は驚くべきインタラクティブな流体シミュレーションプラグインで、極めて低いパフォーマンス消費で圧倒的な効果を制作できます：

    • 作者YouTube：https://www.youtube.com/c/AndrasKetzer
    • ユーリアルマーケットプレイス：https://www.unrealengine.com/marketplace/en-US/product/fluidninja-live
    • ディスカッションコミュニティ（Discord）：https://discord.com/invite/rgEtwua2tu

    作者のYoutubeには多くの動画チュートリアルがあります：

    • FluidNinja LIVE - ALL IN ONE TUTORIAL and making FX from scratch - YouTube

    • FluidNinja 中国語講座 - 陶仁賢

    主要なBlueprint¶

    NinjaLiveComponent¶

    NinjaLiveComponentはFluidNinjaのコアで、静的メッシュ（一般的にはパッチ、トレースメッシュ（Trace Mesh） と呼ばれる）を搭載する必要があります。流体シミュレーションの最終結果はトレースメッシュのマテリアルとして出力されます：

    上図の赤いパッチがトレースメッシュです

    NinjaLive¶

    NinjaLiveはFluid Ninjaが提供するデフォルトのActorで、NinjaLiveComponentのパラメータをラップし、大多数のケースに対応するトレースパッチを含んでいます。NinjaLiveComponentの設定を簡略化し、以下のような追加機能を提供します：

    • ActivationVolumeを通じてNinjaFluidをカリング・スリープさせ、ActivationVolumeに入った場合にのみNinjaLiveComponentをアクティブにする
    • InteractionVolumeを通じてより細かい粒度でインタラクション領域を設定する

    NinjaLive_Utilities¶

    NinjaLive_Utilities（Blueprint Actor）は以下のような便利なデバッグ機能を提供します：

    • このBlueprintに最も近いプレイヤーを自動制御する
    • マウスを表示する
    • アンチエイリアス、デプスオブフィールド、モーションブラーの品質を調整する
    • エディタの120FPS制限を解除する
    • ...

    このBlueprintをシーンにドラッグして設定できます：

    シミュレーションプロセス¶

    FluidNinjaのアセットディレクトリには、Helpという名前のBlueprintがあります：

    この中にFluid Ninjaシミュレーションのフローチャートが詳細に記述されています：

    NinjaFluidのコアは以下の点にあります：

    • Density（密度） テクスチャと Velocity（速度） テクスチャを構築する
    • ノイズ（Noise） を重ねて流体のランダム性を高める
    • ブラシ（Brush） を調整して流体の形状を制御する
    • 出力マテリアル（Output Material） を組み合わせる
    • 最終結果を トレースメッシュ（Trace Mesh） のマテリアル表面に出力する
    • 所望の結果を得る：

    • Densityはシングルチャンネルテクスチャで、値域は[0,1]で、現在位置の流体密度を表します。
    • Velocityはデュアルチャンネルテクスチャで、値域は[0,1]で、現在位置の流体のベクトル速度を表します。[0,1]に正規化されているため、速度0は実際にはRG値(0.5,0.5)に対応します。上図では：
    • VelocityテクスチャのRチャンネルは水平速度に対応し、値が<0.5の場合流体は左に、>0.5の場合右に流れます
    • VelocityテクスチャのGチャンネルは垂直速度に対応し、値が<0.5の場合流体は上に、>0.5の場合下に流れます
    • FluidNinjaは3チャンネルマテリアルの入力を許可し、RGチャンネルはVelocityを、BチャンネルはDensityを表します

    使用フロー¶

    制作プロセスでは、本質的に NinjaLiveComponent を操作することになり、その 設定項目カテゴリ（Categories） は以下の通りです：

    • Live Activation ：Disable Componentオプションのみが存在し、Blueprintを通じて動的に設定してカリングできます。
    • Live Interaction ：インタラクションに関するすべての設定、例えばインタラクション対象のフィルタリング、トレースメッシュの向き・ロック、ワールド座標オフセットなど。
    • Live Brush Setting ：ブラシのパラメータ設定。
    • Live Generic ：一般設定で、主に効果のプリセット、入力、出力を調整します。
    • Live Performance ：パフォーマンス設定で、効果の反復回数、FPS範囲制限、LODなどを設定できます。
    • Live Compatibility ：互換性設定で、コリジョンチャンネル、入力の上書きなどを設定できます。
    • Live Debug ：デバッグ設定で、ヒント情報を印刷するためのいくつかのチェックボックスが提供されます。
    • Live Raymarching ：Raymarchingを設定します。
    • Live Memory Management ：メモリ管理を設定します。

    入力の構築¶

    ここでの入力は主に 密度（Density） と 速度（Velocity） を指し、関連する入力設定パラメータは主に NiagaraComponent のLive Genericカテゴリ下にあります。Fluid Ninjaの入力ソースは以下の種類があります：

    • 静的テクスチャ
    • 動的マテリアル
    • シーンカメラキャプチャ
    • レンダーターゲット（RenderTarget）
    • ストリーミングビデオ
    • マウス入力
    • シーンインタラクション：静的メッシュ、動的メッシュ、スケルタルメッシュ、破壊可能オブジェクト...

    上記の入力は独立しているわけではなく、共存可能です。FluidNinjaは複数の入力を混合します。詳細はHelp.uassetのフローチャートを参照してください。

    マップContent/FluidNinjaLive/Tutorial/Levels/NinjaLive_Level03_SimulationInputs_LIVE17.umapには、NinjaFluid入力の完全なサンプルがあります。以下にこれらの入力のキーステップを記録します：

    動的マテリアル（Material）¶

    マテリアルの入力設定は NinjaComponent の Live Generic カテゴリ下にあります：

    • Input Materials パラメータで使用可能な入力マテリアルを追加できます。複数追加することで、 NinjaLive_PresetManager で切り替えてプレビューできます。
    • Input Material Selected インデックスを調整して、現在使用する入力マテリアルを選択します。
    • RGB-Input Material をチェックすると、マテリアルのRGチャンネルがVelocityテクスチャとして、BチャンネルがDensityテクスチャとして使用されます。そうでない場合、 デフォルトではマテリアルのRチャンネルのみがDensityテクスチャとして使用されます
    • Input Material Clamp をチェックすると、UV座標が[0,1]以外の画像がクリップされます。

    Ninja Fluidの入力マテリアルには、マテリアルドメインをポストプロセスに設定し、投影光線によるシャドウ検出をオフにする必要があります：

    コリジョンインタラクション¶

    Fluid Ninjaは物理コリジョンを入力として使用し、インタラクティブな流体効果を実現できます。簡単なサンプルは以下の通りです：

    • NinjaLiveActorを追加する

    • Trace Mesh SizeとInteraction Volume Sizeを(5,5,1)に設定する

    • NinjaLiveComponent\Live Brush Settingsを設定する。そうしないと、コリジョンブラシが小さすぎて結果が見えない場合があります

      • Brush Scaled By Interacting Obj Sizeをチェックする
      • Primitive Obj Brush Scaleを20に設定する

    • 小白人を追加すると、以下の効果が見られます：

    この効果はUEの物理コリジョンメカニズムによって実現され、その完全なパラメータはすべて NinjaLiveComponent\Live Interaction にあります：

    • Continuous Interaction with Owner Actor ：このコンポーネントを持つActorと持続的にインタラクションする
    • Continuous Interaction incluisve Obj Type ：インタラクションするコリジョンオブジェクトタイプをフィルタリングする
    • Continuous Interaction Component Name ：インタラクションするコンポーネント名をフィルタリングする
    • Continuous Interaction Bone Names Exact ：インタラクションする骨格名をフィルタリングする
    • Single Target Mode ：シングルターゲットモード。オンにすると、FluidNinjaはコリジョンによって生成された画像がすべて一つのターゲットから生成されたとみなし、コリジョンパスをスムーズにし、断層をなくすことができます（補間）
    • Single Target Type
    • Single Target Mode Skeletal Mesh Index
    • Single Target Move Set Sim Speed
    • Speed Influence Factor ：速度影響因子
    • Clamp Max Velocity ：最大速度を截断する
    • Camera Facing Trace Mesh ：TraceMeshが常にカメラを面向く
    • Camera Facing Lock Y-Axis ：カメラのY軸をロックする
    • Use Legacy Camera Facing
    • Trace Mesh Translucent Sort Prio
    • Use Custom Trace Source ：カスタムトレースリソースを使用する。オンにすると、以下の位置をカメラ位置としてコリジョン検出を行う
    • Custom Trace Source Position ：自動トレースリソースの位置
    • Trace Mesh Moving in World Space ：TraceMeshがワールド空間にある
    • Movement Not Quantized to Steps OnAxis
    • Movements is Locked on This axis ：特定の軸の移動をロックする
    • Force Trace Mesh to Custom Vertical Pos
    • Force Trace Mesh Vertical Position ：TraceMeshの位置をロックする
    • Enable Paint Buffer Offset in World Spacing ：ワールド空間でのペイントバッファオフセットを有効にする
    • Simple Painter Mode ：単純なペイントモードで、コリジョン入力はない

    NinjaLiveActor の場合、上記パラメータがさらにカプセル化され、以下のパラメータを調整できます：

    • Overlap Based Interaction ：コリジョンインタラクションを有効にする
    • Interaction Volume Size ：インタラクションボリュームサイズ
    • 以下のパラメータは どのオブジェクトがインタラクションボリュームと「作用」できるか をフィルタリングするために使用されます。
    • Track Actor Primitive Components With Tag ：このタグを持つコンポーネントを追跡する
    • Track Actor Skeletal Mesh Components With Tag ：このタグを持つスケルタルメッシュコンポーネントを追跡する
    • Overlap Filter Inclusive Obj Tab ：含めるオブジェクトコリジョンタイプ
    • Overlap Filter Inclusive Bone Name Exact ：含める骨格名。空の場合、すべての骨格が処理される
    • Overlap Filter Inclusive Bone Name Partial ：含める骨格名フィールド。例えばFootを入力すると、Footを含むすべての骨格名が含まれる
    • Exclude Specific Actors from Overlap ：オーバーラップから除外する特定のActorタイプ
    • Auto Exclude Large Overlapping Objects ：大きなオーバーラップオブジェクトを自動的に除外する

    ブラシの調整¶

    ブラシはFluidNinja入力テクスチャの作用領域のスケール因子を制御するために使用され、そのパラメータ設定は以下の通りです：

    いくつかのキーパラメータ：

    • Brush Scaled Inversely by Trace Mesh Size ：ブラシがトレースメッシュのサイズに応じてスケーリングされる
    • Brush Scaled by Interacting Obj Size ：ブラシがインタラクションオブジェクトのサイズに応じてスケーリングされる
    • Use Obj Bounds Instead of Size ：インタラクションオブジェクトの境界をブラシサイズとして使用する
    • Global Brush Scale ：グローバルブラシスケール係数

    コリジョンインタラクションの効果がほとんど見えない場合、ブラシが小さすぎる可能性が高いです

    まとめ¶

    FluidNinjaのアイデアは巧妙で、使用するには少し手間がかかりますが、キーステップは明確です：

    • シミュレーションプロセスに必要なDensity（密度）テクスチャとVelocity（速度）テクスチャを構築し、適切なブラシとプリセットを使用し、対応するマテリアルを組み合わせて最終的に所望の効果を表示します。

    优缺点¶

    • FluidNinjaは2Dパッチを使用して3D視覚効果を偽装し、通常のパーティクル流体シミュレーションよりもはるかに低いパフォーマンス消費です。しかし、十分にリアルな3D効果を偽装するには、十分にリアルな2D入力が必要です。そうでない場合、特定の視点からFluidNinjaのトレースメッシュパッチが容易に看破される可能性があります。
    • FluidNinjaは流体の入力を構築する多くの方法（テクスチャ、マテリアル、RT、Niagara、カメラ...）を提供し、ほとんどの開発ニーズを満たすことができます。しかし、細部が多く使用しにくく、所望の効果を自由自在に制作するには深い学習が必要です。
    • FluidNinjaはパーティクルを完全に代替することはできず、インタラクティブな 流体シミュレーション（煙、炎、水など）により適しています。
