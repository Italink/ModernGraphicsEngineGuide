    オーディオ開発¶

    長らくレンダリングはグラフィックスエンジンの注目点でしたが、オーディオは開発者の注意を引きにくいように思われます。しかし実際、オーディオは没入型のインタラクティブ体験を高めるだけでなく、画面の表現力をさらに向上させることができます。

    筆者もこれをきっかけにプログラム開発への情熱を燃やし、オーディオにより良いグラフィックス表現効果を与えるために、グラフィックスエンジンの分野に入ったのです。

    この記事では、基礎的なオーディオ知識から始め、UE5でよく使われるオーディオインターフェース、そして一般的な**デジタル信号処理（Digital Signal Process）**アルゴリズムを紹介し、最後に**Meta Sound**を取り上げます。

    筆者は専門のオーディオ開発者ではないため、誤りがあればご指摘ください。

    オーディオを知る¶

    オーディオとは？¶

    周知のように、音は振動によって生まれます。具体的には次のようになります。

    画像元：How Does Sound Travel From One Medium To Another? (scienceabc.com)

    音の本質をよく説明している動画が2つあります。

    • What is Sound-The Dr. Binocs Show
    • What is Sound-BranchEducation

    私たちは通常、音を連続的な波形として認識します。例えば次のように。

    コンピュータの記憶精度は有限です（0から1の間には無限の小数が存在します）。音データをコンピュータに保存する場合、2つの次元で精度処理の問題に直面します。

    • 時間
    • 振幅

    この問題を解決するために、**パルス符号変調技術（Pulse Code Modulation、略称PCM）**を使用して、音の**連続信号（Continuous Signal）**を**離散信号（Discrete Signal）**に変換します。

    まず、**サンプリング（Sampling）**によって時間次元の精度分割を行います。

    時間次元のサンプリング精度パラメータは**サンプリングレート（Sample Rate）**で、単位時間（1秒）内に音信号をサンプリングする回数を表します。一般的なサンプリングレートには44100 Hz、48000Hzなどがあります。

    サンプリングデータを取得した後、さらに**量子化（Quantize）**によって振幅次元の精度分割を行います。

    振幅次元のサンプリング精度は**ビット深度（Bits Per Sample）**で、1つのオーディオサンプルのbit記憶精度を表します。一般的なビット深度には8 bit、16 bit、24 bit、32 bitがあります。例えば8 bitは1バイトに相当し、表現できる数は256(2^8)個で、符号位を考慮すると数値範囲は[-128,127]となり、128の振幅グラデーションを持つと見なすことができます。

    サンプリングと量子化について、優れた記事があります。

    • 音视频开发基础入门｜声音的采集与量化、音频数字信号质量、音频码率 - 知乎 (zhihu.com)

    最終的に得られるデータは通常**ウェーブテーブル/ウェーブグラフ（Wave Table）**と呼ばれます。ビット深度の記憶精度を考慮しない場合、振幅を浮動小数点で表現すると、C++では次のような記憶構造で表すことができます。

    std::vector<float> WaveTable = {
    sample0,sample1,sample2,sample3,sample4...
}

    コンピュータのサウンド設定を開くと、各オーディオデバイス（入力または出力）に関連する設定があることがわかります。

    現実世界では、**音源（Sound Source）**は周囲に大量の運動粒子を放出します。一部の粒子は直接人間の耳に入り、別の一部は周囲の物体と1回または複数回衝突した後に耳に入ります。このような複雑な周囲環境下では、通常、人間の両耳が異なるオーディオデータを受信するため、オーディオにいわゆる**空間感**が生まれます。

    したがって、オーディオをコンピュータに保存する際にこの空間感を保持するために、複数のオーディオデータを保存します。この数を**チャンネル数（Number Of Channels）と呼びます。チャンネルが1つだけのオーディオを**モノラル（Mono）、2つのチャンネルを持つオーディオを**ステレオ（Stereo）**と呼びます。

    複数チャンネルのオーディオサンプルは交差して組み合わされ、1つの組み合わせを**オーディオブロック（Block）**と呼びます。

    ステレオの場合、記憶構造は次のようになります。

    std::vector<float> WaveTable = {
    channel0_sample0, channel1_sample0,     // Block 0
    channel0_sample1, channel1_sample1,     // Block 1
    channel0_sample2, channel1_sample2,     // Block 2
    channel0_sample3, channel1_sample3,     // Block 3
    channel0_sample4, channel1_sample4,     // Block 4
    ...
}

    4チャンネルも同様です。

    std::vector<float> WaveTable = {
    channel0_sample0, channel1_sample0, channel2_sample0, channel3_sample0,     // Block 0
    channel0_sample1, channel1_sample1, channel2_sample1, channel3_sample1,     // Block 1
    channel0_sample2, channel1_sample2, channel2_sample2, channel3_sample2,     // Block 2
    channel0_sample3, channel1_sample3, channel2_sample3, channel3_sample3,     // Block 3
    channel0_sample4, channel1_sample4, channel2_sample4, channel3_sample4,     // Block 4
    ...
}

    通常、Wave Tableはオーディオデバイスで直接再生することはできません。なぜなら、波形データの塊であり、サンプリングレート、ビット深度、チャンネル数などのオーディオのフォーマット情報が含まれていないためです。

    再生可能にするには、さらにオーディオファイルにエンコードする必要があります。

    WAV¶

    *.WAVは最も一般的なサウンドファイル形式の1つで、MicrosoftがWindows向けに開発した標準的なデジタルオーディオファイルです。*.mp3、*.flac、*.aacなどのオーディオ形式とは異なり、無圧縮のオーディオであり、WaveTableのデータの前にオーディオのフォーマットを保存するだけです。

    これに関する完全なドキュメントがあります。

    • WAV文件格式解析及处理 - 简书 (jianshu.com)

    上記の記事をよく読んで、WAV形式の各データの意味を理解してください。

    その後、C++でWAVのファイルヘッダ構造を次のようにメモリアライメントして記述できます。

    struct WavFmtChunk {
    uint8_t chunkID[4] = { 'f','m','t',' ' };
    int32_t chunkSize;
    int16_t audioFormat;
    int16_t numChannels;
    int32_t sampleRate;
    int32_t byteRate;
    int16_t blockAlign;
    int16_t bitsPerSample;
};

struct WavDataChunkHeader {
    uint8_t chunkID[4] = { 'd','a','t','a' };
    int32_t chunkSize;
};

struct WavRiffChunk {
    uint8_t chunkID[4] = { 'R','I','F','F' };
    int32_t chunkSize;
    uint8_t format[4] = { 'W','A','V','E' };
    WavFmtChunk fmtChunk;
    WavDataChunkHeader dataChunkHeader;
};

typedef WavRiffChunk WavHeader;

    C++でデータを保存する場合、通常std::vector<uint8_t>を使用します。波形データをWavファイルに書き込む場合は、次のような関数を使用できます。

    void writeWavFile(std::string filePath, int numChannels, int sampleRate, int bitsPerSample, std::vector<uint8_t> waveTable) {
    WavHeader header;
    header.fmtChunk.audioFormat = 0x0001;           // PCM形式に対応する数値は0x0001
    header.fmtChunk.chunkSize = 16;                 // PCM形式のオーディオ形式は16バイトを占める。他の形式の場合は16より大きくなり、ファイルヘッダの総サイズが44より大きくなる可能性がある
    header.fmtChunk.numChannels = numChannels;
    header.fmtChunk.bitsPerSample = bitsPerSample;
    header.fmtChunk.sampleRate = sampleRate;
    header.fmtChunk.blockAlign = header.fmtChunk.numChannels * header.fmtChunk.bitsPerSample / 8;
    header.fmtChunk.byteRate = header.fmtChunk.sampleRate * header.fmtChunk.blockAlign;
    header.dataChunkHeader.chunkSize = waveTable.size();
    header.chunkSize = sizeof(header.format) + sizeof(header.fmtChunk) + sizeof(header.dataChunkHeader) + waveTable.size();
    std::ofstream out(filePath, std::ios::out | std::ios::binary);      //必ずstd::ios::binaryを使用する。そうしないとデータが乱れる
    assert(out.is_open() && "Can`t Write File");
    out.write(reinterpret_cast<char*>(&header), sizeof(WavHeader));
    out.write(reinterpret_cast<char*>(waveTable.data()), waveTable.size());
    out.close();
}

    読み取りも非常に簡単です。

    std::vector<uint8_t> readWavFile(std::string filePath) {
    WavHeader header;
    std::ifstream in(filePath, std::ios::in | std::ios::binary);                //必ずstd::ios::binaryを使用する。そうしないとデータが乱れる
    assert(in.is_open() && "Can`t Read File");
    in.read(reinterpret_cast<char*>(&header), sizeof(header));
    int waveTableSize = header.dataChunkHeader.chunkSize;                       //波形データのサイズを取得
    std::vector<uint8_t> waveTable(waveTableSize);      
    in.read(reinterpret_cast<char*>(waveTable.data()), waveTableSize);
    return waveTable;
}

    次に、オーディオ波形を生成します。**正弦波（Sine Wave）**は基本的な波形の1つで、その関数式は次のとおりです。 $$ y(Time) = Amplitude * sin(2 * PI * Frequency * Time + PhaseOffset) + Bias $$

    関数式に基づいて、次のような関数を作成できます。

    const double M_PI = 3.1415926535;
std::vector<uint8_t> generateSineWave(int timeLengthSec,    // 正弦波の長さ（単位：秒）
                                            int frequency,      // 正弦波の周波数
                                            float amplitude,    // 正弦波の振幅
                                            int numChannels,    // オーディオのチャンネル数
                                            int sampleRate,     // サンプリングレート
                                            int bitsPerSample   // ビット深度
                                           ) {
    int numBlocks = timeLengthSec * sampleRate;                         // オーディオブロックの数
    amplitude = std::clamp(amplitude, 0.01f, 1.0f);                     // 振幅の大きさを制限。std::clampはC++17が必要
    std::vector<uint8_t> waveTable;                             
    waveTable.resize(numBlocks * numChannels * bitsPerSample / 8);      // オーディオデータに必要なメモリサイズを計算
    int step = bitsPerSample / 8;
    for (int i = 0; i < numBlocks; i++) {
        float time = i / (float)numBlocks * timeLengthSec;      // 時間点
        float sampleValue = amplitude * std::sin(2 * M_PI * frequency * time);      //対応する時間点のサンプル値を計算
        // sampleValueをwaveTableに書き込む方法を考える必要がある
    }
    return waveTable;
}

    上記のコードには次の難題があります。

    • 正弦波の関数によってfloat型のサンプル値が得られますが、ビット深度は8 bit、16 bit、24 bit、32 bitの可能性があります。floatを対応するビット深度のデータに変換するにはどうすればよいですか？

    一般的な方法は、既存のデータ型を利用して対応するデータビットを割り当てることです。例えば次のように。

    const int PCMS16MaxAmplitude = 32767;    // 16 bitの数値範囲は[-32768,32767]。ここでは最小の絶対値（32767）を取り、越境を回避する
void write16BitSampleValue(uint8_t* dataPtr, float sampleValue) {
    (*reinterpret_cast<int16_t*>(dataPtr)) = sampleValue * PCMS16MaxAmplitude;
}

    ビット演算を利用して埋めることもできます。

    const int PCMS24MaxAmplitude = 8388607;
void write24BitSampleValue(uint8_t* dataPtr, float sampleValue) {
    int value = sampleValue * PCMS24MaxAmplitude;
    dataPtr[0] = value & 0xFF;
    dataPtr[1] = (value >> 8) & 0xFF;
    dataPtr[2] = (value >> 16) & 0xFF;
}

    以上をまとめて、次のような変換関数テーブルを整理できます。

    const int PCMS8MaxAmplitude = 127;
const int PCMS16MaxAmplitude = 32767;
const int PCMS24MaxAmplitude = 8388607;
const int PCMS32MaxAmplitude = 2147483647;

typedef std::function<void(uint8_t*, float)> SampleValueWriteFunction;
static std::map<uint8_t, SampleValueWriteFunction> SampleValueWriteFunctions = {
    {8,[](uint8_t* dataPtr, float sampleValue) {
         // なぜここに偏差を加えると波形が正しくなるのか、筆者は不明=.=
        (*reinterpret_cast<int8_t*>(dataPtr)) = sampleValue * PCMS8MaxAmplitude + PCMS8MaxAmplitude;  
    }},
    {16,[](uint8_t* dataPtr, float sampleValue) {
        (*reinterpret_cast<int16_t*>(dataPtr)) = sampleValue * PCMS16MaxAmplitude;
    }},
    {24,[](uint8_t* dataPtr, float sampleValue) {
        int value = sampleValue * PCMS24MaxAmplitude;
        dataPtr[0] = value & 0xFF;
        dataPtr[1] = (value >> 8) & 0xFF;
        dataPtr[2] = (value >> 16) & 0xFF;
    }},
    {32,[](uint8_t* dataPtr, float sampleValue) {
        (*reinterpret_cast<int32_t*>(dataPtr)) = sampleValue * PCMS32MaxAmplitude;
    }}
};

typedef std::function<float(uint8_t*)> SampleValueReadFunction;
static std::map<uint8_t, SampleValueReadFunction> SampleValueReadFunctions = {
    {8,[](uint8_t* dataPtr) {
        return ((*reinterpret_cast<int8_t*>(dataPtr)) - PCMS8MaxAmplitude) / float(PCMS8MaxAmplitude);
    }},
    {16,[](uint8_t* dataPtr) {
        return (*reinterpret_cast<int16_t*>(dataPtr)) / float(PCMS16MaxAmplitude);
    }},
    {24,[](uint8_t* dataPtr) {
        int value = dataPtr[2];
        value <<= 8;
        value |= dataPtr[1];
        value <<= 8;
        value |= dataPtr[0];
        return value / float(PCMS24MaxAmplitude);
    }},
    {32,[](uint8_t* dataPtr) {
        return (*reinterpret_cast<int32_t*>(dataPtr)) / float(PCMS32MaxAmplitude);
    }}
};

std::vector<uint8_t> generateSineWave(int timeLengthSec, int frequency, float amplitude, int numChannels, int sampleRate, int bitsPerSample) {
    int numBlocks = timeLengthSec * sampleRate;                         // オーディオブロックの数
    amplitude = std::clamp(amplitude, 0.01f, 1.0f);                     // 振幅の大きさを制限。std::clampはC++17が必要
    std::vector<uint8_t> waveTable;                             
    waveTable.resize(numBlocks * numChannels * bitsPerSample / 8);
    int step = bitsPerSample / 8;                                       //各サンプルのバイトスパンを計算
    uint8_t* waveTablePtr = waveTable.data();
    SampleValueWriteFunction writer = SampleValueWriteFunctions.at(bitsPerSample);
    for (int i = 0; i < numBlocks; i++) {
        float time = i / (float)numBlocks * timeLengthSec;              // 現在のオーディオブロックに対応する時間
        float sampleValue = amplitude * std::sin(2 * M_PI * frequency * time);      //現在の時間に対応する正弦値
        for (int channelIndex = 0; channelIndex < numChannels; channelIndex++) {    //すべてのチャンネルで同じ値を使用
            writer(waveTablePtr, sampleValue);
            waveTablePtr += step;
        }
    }
    return waveTable;
}

std::vector<uint8_t> readWavFile(std::string filePath) {
    WavHeader header;
    std::ifstream in(filePath, std::ios::in | std::ios::binary);                //必ずstd::ios::binaryを使用する。そうしないとデータが乱れる
    assert(in.is_open() && "Can`t Read File");
    in.read(reinterpret_cast<char*>(&header), sizeof(header));
    int waveTableSize = header.dataChunkHeader.chunkSize;                       //波形データのサイズを取得
    std::vector<uint8_t> waveTable(waveTableSize);      
    in.read(reinterpret_cast<char*>(waveTable.data()), waveTableSize);
    return waveTable;
}

int main() {
    assert(sizeof(WavHeader) == 44 && "WAV Header Size Error");

    int numChannels = 2;            //モノラル
    int sampleRate = 48000;         //サンプリングレートは48000HZ
    int bitsPerSample = 16;         //各オーディオサンプルは16Bit、すなわち2バイトを占める
    int auidoLengthSec = 2;         //2秒の正弦波を生成
    int sineFrequency = 440;        //正弦波の周波数
    float sineAmplitude = 0.8f;     //正弦波の振幅

    std::vector<uint8_t> waveTable = generateSineWave(auidoLengthSec, sineFrequency, sineAmplitude, numChannels, sampleRate, bitsPerSample);

    writeWavFile("./sineWave.wav", numChannels, sampleRate, bitsPerSample, waveTable);

    std::vector<uint8_t> generateSineSurroundWave(int timeLengthSec, int frequency, float amplitude, int numChannels, int sampleRate, int bitsPerSample) {
    assert(numChannels == 2);

    int numBlocks = timeLengthSec * sampleRate;                         // オーディオブロックの数
    amplitude = std::clamp(amplitude, 0.01f, 1.0f);                     // 振幅の大きさを制限。std::clampはC++17が必要
    std::vector<uint8_t> waveTable;
    waveTable.resize(numBlocks * numChannels * bitsPerSample / 8);
    int step = bitsPerSample / 8;                                       //各サンプルのバイトスパンを計算
    uint8_t* waveTablePtr = waveTable.data();
    SampleValueWriteFunction writer = SampleValueWriteFunctions.at(bitsPerSample);

    float leftEarPos[2]  = { -5,0 };                                    // 左耳の位置（X，Y）
    float rightEarPos[2] = {  5,0 };                                    // 右耳の位置（X，Y）
    float radiusOfSurround = 10;                                        // サラウンドオーディオの半径
    float audioAttenuationFactor = 0.7;                                 // 音の減衰係数。例えば0.7は、単位長さごとにオーディオが元の0.7倍に減衰することを意味する
    float periodSec = 2;                                                // 1周するのにかかる時間（単位：秒）。2は2秒ごとに1周することを意味する

    for (int i = 0; i < numBlocks; i++) {
        float time = i / (float)numBlocks * timeLengthSec;                          // 現在のオーディオブロックに対応する時間
        float sampleValue = amplitude * std::sin(2 * M_PI * frequency * time);      // 現在の時間に対応する正弦値

        float angle = 2 * M_PI * time / periodSec;                                  // 現在の回転角度を計算
        float audioSourcePos[2] = {                                                 // 現在の音源の位置を計算
            radiusOfSurround * std::cos(angle),
            radiusOfSurround * std::sin(angle)
        };

        float leftEarDistance  = sqrt(pow(leftEarPos[0] - audioSourcePos[0], 2) + pow(leftEarPos[1] - audioSourcePos[1], 2));       // 音源から左耳までの距離
        float leftSampleValue = sampleValue * pow(audioAttenuationFactor, leftEarDistance);                                         // 距離に基づいて、減衰後のオーディオサンプル値を計算
        writer(waveTablePtr, leftSampleValue);                                                                                      // 左チャンネルに書き込む
        waveTablePtr += step;

        float rightEarDistance = sqrt(pow(rightEarPos[0] - audioSourcePos[0], 2) + pow(rightEarPos[1] - audioSourcePos[1], 2));     // 音源から右耳までの距離
        float rightSampleValue = sampleValue * pow(audioAttenuationFactor, rightEarDistance);                                       // 距離に基づいて、減衰後のオーディオサンプル値を計算
        writer(waveTablePtr, rightSampleValue);                                                                                     // 右チャンネルに書き込む
        waveTablePtr += step;
    }
    return waveTable;
}

int main() {

    ゲームプロジェクトではオーディオキャプチャのニーズは少ないため、ここでは簡単に紹介します。

    ゲーム内オーディオキャプチャ¶

    ゲーム内オーディオキャプチャはUEが提供するインターフェース**ISubmixBufferListener**を使用します。

    /** 特定のサブミックスからオーディオデータを受信するための抽象インターフェース */
class ISubmixBufferListener
{
public:
    virtual ~ISubmixBufferListener() = default;

    /**
    特定のサブミックスが新しいバッファをレンダリングしたときに呼び出される
    @param OwningSubmix 新しいバッファをレンダリングしたサブミックスオブジェクト
    @param AudioData        オーディオバッファへのポインタ
    @param NumSamples       オーディオバッファ内のオーディオサンプル数
    @param NumChannels      バッファ内のオーディオのチャンネル数（例：ステレオは2、5.1は6など）
    @param SampleRate       オーディオバッファのサンプリングレート
    @param AudioClock       オーディオレンダリング開始からのダブルオーディオクロック値
    */
    virtual void OnNewSubmixBuffer(const USoundSubmix* OwningSubmix, float* AudioData, int32 NumSamples, int32 NumChannels, const int32 SampleRate, double AudioClock) = 0;

    /**
     * FMixerSubmix::IsRenderingAudio()で次のオーディオバッファのためにサブミックスが自身を無効にするか評価する場合に呼び出される
     * これがtrueを返す場合、FMixerSubmix::IsRenderingAudio()はtrueを返す
     * それ以外の場合、サブミックスは再生中のサウンド、子サブミックスなどを評価して自動的に無効にするかどうか判断する
     *
     * これは毎回評価されるときに呼び出される
     * 断続的にオーディオをレンダリングするISubmixListenersは、作業がある場合にのみtrueを返す必要がある
     */
    virtual bool IsRenderingAudio() const
    {
        return false;
    }
};

    DSP¶

    UE内置了一个非常完善的DSP模块—— SignalProcessing

    你几乎能在其中找到你想要的任何东西：

    这是一些常用的结构和函数：

    • Audio::TCircularAudioBuffer ：环形缓冲区，常用于流式音频的存储。
    • Audio::TSampleBuffer ：用于将RawPCM数据转换为对应位深的可采样数据，类似于提供之前我们提供的SampleValueWriteFunction，不过只支持int16和float。
    • Audio::FResampler ：重采样器，用于修改音频的采样率。
    • Audio::FWindow ：用于生成窗函数，支持Hamming，Hann，Blackman。
    • Audio::TSlidingWindow ：滑动窗口。
    • Audio::IFFTAlgorithm ：提供基础的FFT算法，提供FFFTFactory::NewFFTAlgorithm(...)创建。
    • Audio::FBiquadFilter ：双二阶滤波器。
    • Audio::FSpectrumAnalyzer ：频谱分析仪，支持振幅谱，CQT谱。
    • Audio::FAsyncSpectrumAnalyzer ：执行在异步线程的频谱分析仪，功能同上。
    • ConstantQ.h：提供了一系列支持常量Q变换的结构，CQT常用于音乐的频谱可视化，它相较于FFT有更好的节奏表现效果。

    对于频谱分析，UE还有一个模块AudioSynesthesia来扩展相关的功能。

    它支持 CQT ， Onset（迸发） ， Loudness（响度） ， Meter 的分析，可惜的是大多是一些 NRT（非实时） 接口，它要求音频数据必须是在编辑器时导入的资产，不过它里面很多算法结构可以供大家参考。
